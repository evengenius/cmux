# cmux

*Русский · [English version](README.en.md)*

**Кратко** — TUI в стиле Midnight Commander, который позволяет запускать несколько сессий `claude` в одном окне терминала. Двухрядная панель сверху: вверху проекты (уникальные каталоги), внизу чаты внутри активного проекта. Сквозной поиск по сессиям, поиск по истории текущего чата, файловый браузер, нижняя shell-панель, OS-нотификации когда сессия ждёт твоего ответа.

---

## Описание

TUI-обёртка для CLI [Claude Code](https://claude.com/claude-code). Ведите несколько проектов и десятки чатов параллельно: каждая вкладка — отдельный `claude` в реальном PTY, рендерится точно как в обычном терминале. Активные чаты группируются по cwd-каталогу (проекту) — переключаться между проектами и между чатами внутри проекта можно по отдельности.

## Чем отличается от обычного `claude`

### Группировка проектов и чатов

- **Двухрядный chrome сверху**: строка 0 — список проектов (уникальные cwd среди открытых табов), строка 1 — чаты внутри активного проекта.
- `F2` создаёт новый чат **в текущем проекте** (cwd активного таба, не cwd запуска cmux).
- `F6 → OpenHere` стартует чат в выбранном каталоге. Если cwd уже есть среди проектов — чат добавится туда. Если нет — на верхней панели появится новый проект + первый чат в нём.
- При закрытии последнего чата проекта проект исчезает с панели.

### Сессии

- **Боковая панель F3** — список сессий из `~/.claude/projects/`, ограниченный иерархией cwd активного таба. Живой текстовый фильтр, дип-grep по содержимому `.jsonl` через `F5`. `Ctrl+R` форс-рефреш с диска.
- **Глобальный модал Shift+F3** — все сессии, сгруппированные по каталогу. Тот же фильтр, `↑/↓` пропускают заголовки. `Ctrl+R` рефреш.

### Поиск

- **Палитра команд F9** — нечёткий поиск по действиям и сессиям. Здесь же save/switch/delete сохранённых layout-ов и pin/unpin активного таба.
- **Поиск по истории чата Ctrl+F** — overlay снизу PTY. Совпадения подсвечиваются жёлтым прямо в выводе плюс снеппет внизу со счётчиком `N/M`. `↑/↓` шагают по матчам, скроллбэк сам подвигается так, чтобы строка была видна.

### Файлы

- **Боковая панель файлов Ctrl+B** — VSCode-style дерево, ограниченное cwd активного таба; `Space` вставляет относительный путь в инпут claude.
- **Файловый проводник F6** — модальный, по всей файловой системе. На Windows из drive-root (`C:\`) `←` ведёт в виртуальный список дисков. `Space` вставляет абсолютный путь. `Enter` на «OpenHere» — спавнит новый чат в этой cwd.

### Чаты и табы

- **Переименование чата Shift+F2** — модал с pre-fill заголовка. Пустой ввод сбрасывает на cwd-basename.
- **Pin/Unpin** — закреплённые чаты не закрываются по F8/Alt+W, обозначены 📌. Через палитру.
- **Drag-to-reorder** — мышью: вниз на чате A, отпустить на чате B → меняются местами (внутри одного проекта).
- **Бейдж `[N]`** — на неактивном табе показывает количество завершённых ответов (переходов streaming → idle), которые ты пропустил. Сбрасывается при фокусе.

### Команды Claude

- **F4** — sidebar со slash-командами Claude. Подгружает project-local (`<cwd>/.claude/commands/*.md`) и user-global (`~/.claude/commands/*.md`). У каждого пункта бейдж `[project]` / `[user]` плюс встроенные. Описание парсится из YAML-frontmatter `description:` или первой содержательной строки .md.

### Окружение

- **Нижняя shell-панель `` Ctrl+` ``** — встроенный PTY с родительским шеллом (PowerShell / pwsh / bash / zsh / fish / cmd, автодетект через sysinfo). Автоматически `cd` в cwd активного таба при переключении (можно выключить).
- **Bracketed paste** — многострочная вставка из буфера обмена доходит до claude единым куском, без преждевременного submit на каждой `\n`.

### Сигнализация

- **Activity overlay**: `●` (стримит) или `!` (ждёт permission-prompt) после заголовка чата.
- **OS-нотификации** при переходе в AwaitingPermission: терминальный BEL + Windows-toast (через `powershell -EncodedCommand` + WinRT, без доп. зависимостей). На macOS/Linux toast — no-op, BEL работает.
- Паттерны детектирования AwaitingPermission редактируются в config — добавь свои если у claude другая локаль.

### Параллельная работа

- **Broadcast prompt** (палитра → `★ Broadcast prompt to all chats in active project…`) — один текст шлётся всем чатам активного проекта с `\r`. Сценарии: «запусти cargo check во всех», «закоммить готовое».
- **Per-model new tab** (палитра → `★ New tab with model: opus / sonnet / haiku`) — спавн нового чата с `claude --model <name>`.

### Удобства

- **Ctrl+Click на URL** в выводе PTY — открывает в дефолтном браузере ОС (`start` / `open` / `xdg-open`). Регекс отсекает финальную пунктуацию.
- **Видимый скроллбар** справа от чата с `▲`/`█`/`▼`. Клик / drag / колесо. Красные точки на полосе показывают позиции матчей при активном Ctrl+F.

### Layout

- **Auto-save** — текущее состояние пишется в `~/.cmux/layout.json` на каждое изменение (открытие/закрытие чата, смена pin).
- **Auto-restore on startup** — опт-ин (`[layout] auto_restore = true`).
- **Named layouts** — `~/.cmux/layouts/<name>.json`. Через палитру: `★ Save current layout as…`, `⇄ Switch to layout: …`, `✕ Delete saved layout: …`.

### Клик-френдли

- У каждой F-клавиши кнопка в нижней панели; вкладки, проекты, `+`, границы — кликабельны; границы тянутся мышью.

## Требования

- Rust toolchain (>= 1.75) для сборки.
- [Claude Code](https://claude.com/claude-code), доступный в `PATH`:
  - Windows — `claude.cmd`.
  - Linux/macOS — `claude`.
- Windows 10+ — основная платформа (тестируется тут). Linux/macOS поддержка есть, но без живой проверки.

## Установка

```powershell
git clone https://github.com/evengenius/cmux
cd cmux
cargo build --release
# Получившийся бинарь: target/release/cmux.exe (Windows) или target/release/cmux (Unix)
```

Перенесите/симлинкуйте бинарь куда-нибудь в `PATH`, потом запускайте `cmux`.

## CLI

```
cmux [PATH] [--layout NAME] [--resume ID] [--continue]
cmux -h | --help | -V | --version
```

| Аргумент | Что делает |
| --- | --- |
| `PATH` | Стартовая cwd для первого чата (по умолчанию — текущая директория). |
| `--layout NAME` | Применить named layout `~/.cmux/layouts/<NAME>.json` при старте. |
| `--resume ID` | Первый таб = `claude --resume <id>`. |
| `--continue` | Первый таб = `claude --continue` (resume последней сессии в этой cwd). |

Перед запуском raw-mode cmux проверяет наличие `claude` (или `claude.cmd` на Windows) в `PATH`. Если не найден — внятная ошибка вместо непонятного PTY-крэша.

### Мышь

- **Row 0 (проекты)**: клик → переключить проект; двойной клик → закрыть весь проект (с подтверждением); клик по `+ project` → file browser в активной cwd для нового чата.
- **Row 1 (чаты)**: клик → переключить чат; двойной клик → закрыть чат (pinned → подтверждение); правый клик → переименовать; drag (down→up на другом чате) → swap внутри проекта.

- **Боковые панели**: колесо шагает по списку, drag-border — изменить ширину/высоту.

## Конфигурация

Конфиг в `~/.cmux/config.toml`, создаётся с дефолтами при первом запуске. После правки — `F9 → ★ Reload config` без перезапуска (часть полей применяется только к новым панелям/табам).

```toml
[layout]
sidebar_width = 42         # ширина левой панели (Sessions/Commands)
right_sidebar_width = 42   # ширина правой панели (Files)
bottom_height = 12         # высота нижней shell-панели
auto_restore = false       # автовосстановление ~/.cmux/layout.json при старте
scrollback_lines = 10000   # cap PTY-скроллбэка; ~100B × cap × открытых табов

[browser]
show_hidden = false        # показывать .git, .claude и т.п.

[shell]
exe = ""                   # переопределение шелла для нижней панели
args = []                  #   пусто = автодетект из родительского процесса
follow_tab_cwd = true      # при свитче таба нижний шелл делает `cd` в его cwd
# Пример:
# exe = "pwsh.exe"
# args = ["-NoLogo"]

[detect]
# Подстроки (lowercase), по которым cmux считает что claude ждёт твоего
# подтверждения. Add patterns если у тебя другая локаль.
permission_patterns = [
  "do you want to",
  "allow this tool",
  "approve this",
  "(y/n)",
]

[notify]
bell = true    # терминальный BEL при переходе в AwaitingPermission
toast = true   # Windows toast (no-op на других ОС)

[theme]
# Accent — для рамок ВСЕХ модалов / сайдбаров (фокусированных) и т.п.
# cyan | yellow | green | magenta | red | blue | white | gray | light*
accent = "cyan"
# Палитра: `dark` (по умолчанию), `light` (для светлых терминалов;
# инвертирует фоны панелей/инпутов), `auto` (определяет по env COLORFGBG).
mode = "dark"
# Заменить эмодзи (📌, 🔍) на ASCII-аналоги ([*], ?) — для SSH-сессий
# на bare ttys, LANG=C и шрифтов без emoji-поддержки.
ascii_icons = false

[keys]
# Переназначение клавиш на любые nullary Action. Формат:
#   action_name = "key_combo"
# Key: f1..f12, single chars, ctrl-x, alt-shift-f4 и т.п.
# Дефолтные биндинги остаются — это только override / добавление.
# Пример:
#   toggle_search = "f4"     # F4 открывает поиск вместо F4=commands
#   quit          = "ctrl-x" # Ctrl+X выходит дополнительно к F10/Ctrl+Q
#
# Список action_name (snake_case от внутренних Action):
#   new_tab · close_tab · prev_tab · next_tab · rename_active_tab
#   toggle_active_pin · toggle_sidebar · toggle_commands · toggle_help
#   toggle_palette · toggle_browser · toggle_files_sidebar · toggle_search
#   toggle_deep_grep · toggle_mouse · toggle_bottom · toggle_global_sessions
#   prev_project · next_project · open_browser_for_new_project
#   toggle_active_project_pin · new_tab_continue · open_broadcast
#   show_active_usage · show_git_diff · clear_active_chat
#   copy_chat_scrollback · copy_last_response · reopen_last_closed
#   restore_layout · open_save_layout_as · export_session_note
#   reload_config · quit
# (Параметризованные действия — SwitchTab(i), SwitchProject(i),
#  NewTabWithModel(i), InsertSnippet(i) — биндить нельзя, потому что
#  индекс. Используйте Alt+1..9 / Ctrl+Shift+1..9 / палитру.)
```

## Layout (сохранение и восстановление)

- **Авто-save** в `~/.cmux/layout.json` на каждое изменение.
- **Авто-restore** при старте: только если `[layout] auto_restore = true`. Иначе `F9 → ★ Restore previous layout` вручную.
- **Named layouts** в `~/.cmux/layouts/<name>.json`:
  - `★ Save current layout as…` (палитра) — promtим имя, санитизуем (вырезаем `/ \ : * ? " < > |`, control-байты, схлопываем whitespace → `_`).
  - `⇄ Switch to layout: <name>` per layout.
  - `✕ Delete saved layout: <name>` per layout.

Что сохраняется на каждый таб: `cwd`, `session_id` (для resume), `title`, `created_at_unix`, `pinned`.

## Индикаторы

В баре чатов:

- **`●` (жёлтый)** — claude стримит.
- **`!` (красный, мигающий)** — на экране совпадение с `permission_patterns` — claude ждёт.
- **`[N]`** — N завершённых ответов (streaming → idle переходов), которые ты пропустил. Сбрасывается при фокусе.
- **`📌`** — таб закреплён.

В баре проектов: активный проект подсвечивается cyan.

## Поиск по истории чата

`Ctrl+F` открывает overlay снизу PTY. Каждое нажатие клавиши пересчитывает матчи (case-insensitive). Подсветка совпадений — жёлтым прямо в выводе PTY (для видимого окна) плюс снеппет на 1 строку под input'ом со счётчиком `N/M` и расширенным контекстом. `↑/↓` или `Enter` (next) шагают по матчам; vt100-scrollback автоматически подвигается так, чтобы выбранный матч попадал в видимое окно.

Поиск работает по plain-text миррору буфера PTY (ANSI-стрипится, `\r` ресетит строку, `\n` коммитит). Cap буфера — 10k строк, тот же что у vt100.

Известное ограничение: матч через перенос строки (line wrap) не находится — каждая визуальная строка сканится отдельно.

## Как это работает

- Каждая вкладка спавнит реальный PTY через `portable-pty`:
  - Windows: `cmd.exe /c claude.cmd [--resume <id>]`.
  - Unix: `claude [--resume <id>]`.
- Поток вывода идёт в парсер `vt100` (для рендера через `tui-term` + `ratatui`) и параллельно в собственный текстовый mirror (для Ctrl+F).
- Буфер scrollback (10k строк) — наш, поэтому колесо/PgUp/PgDn прокручивают историю, не уходя в нижележащее приложение.
- Дип-grep работает в фоновом потоке через `mpsc`-канал; отмена при смене запроса.
- Родительский шелл для нижней панели определяется через `sysinfo` (PID родителя → имя образа → известный шелл).
- AwaitingPermission detection: смотрит `parser.screen().contents()` lowercased на substring match с `[detect] permission_patterns`.
- OS-toast (Windows): спавнит фоном `powershell.exe -EncodedCommand <UTF-16LE base64>` с WinRT-вызовом ToastNotificationManager. Никаких extra-крейтов.

## Ограничения

- Основная платформа разработки — Windows. Под Linux/macOS код компилируется и должен работать, но я не тестирую там.
- Нижний шелл при `follow_tab_cwd = true` отправляет `cd` через writer — если ты прямо в этот момент что-то печатаешь в шелле, можно перебить ввод. Поэтому follow срабатывает только когда нижняя панель не сфокусирована.
- `session_id` для *новых* (не resumed) вкладок резолвится эвристически при сохранении: cwd вкладки сопоставляется со свежайшим `.jsonl` в `~/.claude/projects/`. Два одновременных таба в одной cwd могут разрешиться неверно.
- Подсветка матча в PTY не пересекает line-wrap.

## FAQ / Troubleshooting

**`claude` не запускается / не найден**
- Убедись, что `claude` (или `claude.cmd` на Windows) есть в `PATH`. Запусти `claude --version` из обычной оболочки — если там не работает, cmux тоже не запустит.
- На Windows проверь, что путь к `npm`-биновому каталогу есть в `PATH` (там лежит `claude.cmd`, см. вывод `npm bin -g`).

**TUI выглядит как мусор / квадратики вместо рамок**
- Терминал не понимает UTF-8 или не имеет шрифта с поддержкой box-drawing. Поставь современный фонт (JetBrains Mono / Fira Code / Cascadia Code) и `LANG=en_US.UTF-8`. Если эмодзи (📌, 🔍) рендерятся плохо или ломают лейаут — поставь `[theme] ascii_icons = true`.

**Светлый терминал — белое на белом**
- Поставь `[theme] mode = "light"`. Включает палитру с тёмным текстом на светлых фонах модалов и сайдбаров.

**Уведомления не приходят при AwaitingPermission**
- Linux: `[notify] osc = true` — большинство Konsole/KDE-семейства подхватят. Других нативных вариантов нет (BEL может быть отключен в настройках терминала).
- macOS: установи hammerspoon / iTerm2 → его настройки уведомлений на BEL. Без этого `bell = true` просто звякает.
- Windows: `toast = true` использует PowerShell-WinRT — должно работать «из коробки». Если нет — проверь что PowerShell в `PATH`.
- Webhook: `webhook = "https://..."` отправляет JSON через `curl`. Если `curl` не в `PATH` — no-op без жалоб.

**Нижняя shell-панель не следует за активным табом**
- Проверь `[shell] follow_tab_cwd = true` в конфиге. Follow срабатывает **только** когда панель не сфокусирована — иначе `cd` мог бы перебить твой ввод.

**Worktree-режим не работает / fall-back на обычный cwd**
- `[git] auto_worktree = true` требует, чтобы текущий каталог был внутри git-репозитория, а `git worktree add` отрабатывал без ошибок (часто ломается, когда `worktree_root` указывает за пределы репо или там уже есть конфликтующее имя ветки). Запусти `git worktree add .cmux-worktrees/test cmux/test` вручную чтобы локализовать причину.

**Mouse-режим конфликтует с tmux / screen**
- Нажми `F7` — переключает между mouse-on и mouse-off. В mouse-off ты можешь выделять текст для копирования через стандартный механизм терминала.

**Палитра F9 слишком длинная**
- В версиях ≥ 0.2 каждое действие имеет префикс категории — `[Tab]`, `[Claude]`, `[Project]`, `[View]`, `[Layout]`, `[App]`. Введи название категории чтобы показать только её действия.
